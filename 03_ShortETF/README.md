# ETF 动量轮动策略系统

一套**自动化的行业 ETF 动量追踪 + 买卖信号系统**：每天（或每 10 个交易日调仓日）运行一次，自动拉取行情数据、计算动量信号、给出 TOP3 持仓建议和申购/赎回操作指令。

---

## 一、这个系统能做什么

| 功能 | 说明 |
|---|---|
| 📊 追踪行业主线 | 78 只行业/主题 ETF 池（覆盖 13 个行业），自动捕捉"正在向上的初步趋势" |
| 🎯 生成买卖信号 | 20日动量 + MACD 双过滤，选出 TOP3 持仓候选，给出场外 C 类基金代码 |
| 🏷️ 费率标注 | 每只候选标注「✅7天免赎 / ⚠️7-30天收费」赎回费率，避免调仓被手续费吃掉 |
| ⚠️ 衰竭预警 | MACD 红柱缩短（多头衰竭）时标注「🟠 衰竭警告」，提示不要追高 |
| 📈 可视化日报 | 每次运行生成 HTML 策略报告，浏览器打开即看 |
| 🔄 池子换血 | 每 1-3 个月一键重建 ETF 池，让新主线（如创新药）自动进池 |

## 三、怎么用（日常操作）

### 1️⃣ 日常更新信号（每次调仓/想看看的时候）

```bash
cd D:\WorkBuddy\etf-analysis\03_ShortETF
python run.py
```

- **耗时**：约 5 分钟（78 只 × 拉取数据）
- **做三件事**：拉最新行情 → 更新数据库 → 生成报告
- **完成后**：打开 `strategy_report.html` 看今日建议

**只想算信号不想联网**（快，几秒）：
```bash
python run.py --signal
```

**常用参数**：
| 参数 | 作用 |
|---|---|
| `--top 5` | 持仓数量改为 5 只（默认 3） |
| `--show-top 15` | 候选池展示 15 只（默认 10） |
| `--universe 19` | 用小池 19 只（调试用） |
| `--limit 90` | 每只只拉 90 根K线（更快，够算60日均线） |

### 2️⃣ 重建 ETF 池（每 1-3 个月一次）

```bash
python rebuild_pool.py
```

- **作用**：从全市场重新筛选行业 ETF，捕捉新主线（比如某行业刚启动）
- **耗时**：当天有缓存 ≈ 秒级；无缓存 ≈ 6 分钟
- **之后记得**：再跑一次 `python run.py` 更新数据

## 四、策略规则（重要！）

### 选股逻辑
1. **候选池**：78 只行业/主题 ETF（13 个行业各 6 只代表）
2. **过滤**：20日动量 > 0 且 MACD 多头（双多才考虑）
3. **排序**：按 20 日动量从高到低取 TOP3，等权持有（各约 1/3）
4. **去重**：同一场外基金只保留一只（避免 3 只半导体 ≈ 1 笔仓）

### 调仓节奏
- **每 10 个交易日**（约两周）收盘后跑一次 `run.py`，按报告 TOP3 调仓
- 当日 14:45 前操作按当日净值

### 持仓纪律（铁律）
| 情况 | 动作 |
|---|---|
| 双多标的不足 3 只 | 按实际数量持有，**不硬凑** |
| 双多标的为 0 | **全部空仓等待**（空仓也是策略一部分） |
| 单只浮亏 -5%（相对买入净值） | 立即赎回，不等调仓日 |
| MACD 死叉（柱变绿） | 立即赎回 |
| 持有 <7 天 | 除非死叉或浮亏>8%，尽量不动（避 1.5% 惩罚费） |

### 报告怎么看（重点）
| 报告里的标签 | 含义 | 怎么做 |
|---|---|---|
| 🟥 多头 | MACD 健康 | 正常持有 |
| 🟠 多头·衰竭警告 | 红柱在缩短，死叉在即 | **别追高**，准备离场 |
| 🟩 空头 | 已死叉 | 执行离场 |
| ✅ 7天免赎 | 赎回费率 0（持有≥7天） | **优先选这类** |
| ⚠️ 7-30天 X% | 赎回要收费 | 10日调仓不划算，换替代 |

## 五、常见问题

**Q1：为什么买场外 C 类而不是场内 ETF？**
小额（<2万）+ 短期调仓场景下，场外 C 类免申赎费（只收 0.25%/年销售服务费），成本远低于场内最低 5 元佣金。**但必须选「✅7天免赎」的 C 类**，否则 7-30 天赎回费 0.5% 会吃掉收益。

**Q2：报告里 TOP3 有收费基金怎么办？**
从下方的「候选池 TOP10」里挑「✅7天免赎」的替代，或空仓等下一期。

**Q3：为什么要空仓等待？**
动量策略的防守方式——市场没有足够强信号时强行买入弱势标的，亏损概率大增。回测验证：0 只双多时空仓是最优解。

**Q4：数据准不准？**
行情来自腾讯自选股，场外费率来自基金公司官网/第三方平台人工核实（11 只已核实）。新标的费率需自行在基金平台核对。

**Q5：报告里的收益靠谱吗？**
回测年化约 46%（验证期），**实盘通常打 5-7 折**；平均回撤约 -15%，需能承受。过往表现不预示未来收益。
