# Investment Learning Journey

## Project Overview

This repository is an open-source textbook for beginners who want to learn long-term investing from scratch.

The goal is **not** to teach short-term trading or speculation.

Instead, this book aims to build a complete investment framework based on long-term investing, passive investing, and financial literacy.

The target audience is someone with **no prior investment experience**.

Every chapter should gradually build knowledge without assuming any financial background.

---

# Writing Style

This project is **a book**, not an online course.

Therefore:

- Do NOT write quizzes.
- Do NOT write homework.
- Do NOT write learning objectives.
- Do NOT write vocabulary sections.
- Do NOT write reflection questions.

Instead,

each lesson should read like a chapter in a professional introductory textbook.

The preferred structure is:

```text
Title

Introduction

Section 1

Section 2

Section 3

...

Summary
```

The writing should be:

- simple
- beginner-friendly
- logically connected
- easy to read
- around CEFR B1–B2 English

Each lesson should naturally lead into the next lesson.

---

# Educational Philosophy

Always explain **why** before explaining **how**.

For example:

Instead of saying

> "An ETF tracks an index."

first explain

> "Why do investors need ETFs?"

Similarly,

introduce each concept because the reader naturally asks the next question.

The book should feel like a conversation rather than a dictionary.

---

# What This Book Is NOT

This book is NOT about:

- Day trading
- Technical analysis
- Candlestick patterns
- Stock picking strategies
- "Getting rich quickly"

Those topics are intentionally excluded.

The focus is long-term investing.

---

# Tone

Write as if explaining investing to a friend who has never invested before.

Avoid unnecessary jargon.

When technical terms are necessary,

introduce them slowly with intuitive explanations and real-world examples.

Readers should always understand **why** something exists before learning **how** it works.

---

# Long-Term Goal

The final repository should read like a professionally written beginner's investment textbook.

Someone who finishes all 40 lessons should have enough knowledge to:

- understand financial news,
- build a simple ETF portfolio,
- avoid common beginner mistakes,
- think like a long-term investor.

The goal is not to make readers experts.

The goal is to build a solid foundation that they can continue to develop throughout their lives.
