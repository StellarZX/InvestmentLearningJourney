# 投资方法与记录

这个仓库记录我的投资方法、执行记录与复盘。

## 目录结构

> **统一入口**：根目录 `run.py` 通过参数调用全部功能：
> - `python run.py --index` → 持仓基金分析报告（生成 `PortfolioReport/YYYYMMDD.html`）
> - `python run.py --plate` → 板块分析报告（生成 `PlateReport/YYYYMMDD.html`，同花顺官方行业+概念板块）
> - `python run.py --portfolio` → 持仓流水管理（浏览器 http://127.0.0.1:8051）
> - `python run.py --export` → 更新本文件第 4 节「组合持仓」表
> - `--sector` 为 `--plate` 的兼容别名（旧行业报告已由板块报告取代）
>
> **目录结构**：
> - `run.py`：统一入口（--index / --plate / --portfolio / --export；--sector 别名）
> - `Code/portfolio_report.py`：**持仓基金分析报告**（读全部持仓 → 拉场外净值 → 三类评分 → 决策建议 → `PortfolioReport/`）
> - `Code/fund_data.py`：**持仓汇总库数据层**（用场外基金代码直接拉净值（天天基金），持仓快照 + 净值 + 估值三张表，报告运行时自动增量更新）
> - `Code/plate_data.py` + `Code/plate_report.py`：**板块分析**（同花顺官方分类：行业 90 + 概念 375，板块指数 K 线算动量/分位/MACD，脚本独立拉取 → `PlateReport/`）
> - `Code/portfolio_app.py`：**持仓流水管理**（增删改查，浏览器 8051；基金名/代码手动输入，带历史补全提示）
> - `Code/export_positions.py`：持仓汇总表生成（第 4 节）
> - `Code/data/`：`portfolio.db`（持仓流水）/ `fund_data.db`（净值+持仓快照）/ `plate.db`（板块清单+K线）
> - `Code/lib/metrics.py`：公共指标引擎 + 三套评分（指数=定投倍数 / 红利=低吸高抛 / 行业=趋势卖出）
> - `PortfolioReport/`、`PlateReport/`：报告输出目录（按日期命名，历史保留）
> - `Foundations/`：投资基础课程；`Glossary/`：电子书
> - `backup_old/`：废弃模块备份（fetch_db/signal_lib/otc_map/dca/db + 旧行情库 market_index/market_industry.db）

## 投资体系

组合分三层：**长期资产（核心）** + **行业基金（增强）** + **现金池（余额宝）**。

| 部分 | 指数（长期资产） | 红利（防守资产） | 行业基金（增强） | 现金池 |
|:--:|:--:|:--:|:--:|:--:|
| 方式 | 每月定投 | 定投 + 波段 | 不固定投入 | 闲钱暂存 |
| 约束 | 战略比例不变 | 单只 ≤¥5,000 | 单只 ≤¥5,000 | 可用现金 |
| 决策 | 定投倍数 | 买入区/卖出区 | 持有/关注/减仓/离场 | — |

### 指数（长期定投）

| 指数 | 沪深300 | 中证500 | 创业板 | 恒生指数 | **合计** |
|---:|---:|---:|---:|---:|---:|
| 比例 | 35% | 25% | 15% | 25% | **100%** |

- 沪深300：中国核心资产（银行、保险、消费、制造业龙头），负责稳定。
- 中证500：中盘成长，提高长期收益。
- 创业板：科技创新，成长性最高，比例不宜太高。
- 恒生指数：配置香港上市的中国优质企业（腾讯、阿里、小米、网易等），很多优秀公司不在 A 股上市。
- 持仓分析覆盖全部指数持仓（含中证红利、恒生红利低波、美股标普500/纳斯达克100），数据按当前持仓涉及基金拉取（持仓驱动）。

**估值调整机制**：战略比例**永远不变**，便宜多买、贵时少买，避免择时：

- 历史分位 <30%：买入 1.5 倍
- 历史分位 30% ~ 70%：正常投入
- 历史分位 >70%：买入 0.5 倍

### 红利（低吸高抛）

红利策略是**均值回归波段**，不是吃股息躺平：价格低时分批买入、上涨一段时间后卖出。

- 买入区：价格分位 <30% + 20 日动量转正（止跌确认，防接飞刀）
- 卖出区：价格分位 >70% + 20 日动量转负（滞涨确认，防卖在半路）
- 中间区间：持有
- 股息率-国债利差是安全垫（越厚 = 跌了拿得住、买错代价小），决定"敢不敢买"而非"该不该买"

### 行业基金（趋势波段）

行业/主题基金（含被动联接与主动混合，策略一致）是**趋势驱动、卖出为主**的波段：

- 核心信号：20 日动量 + MACD + 资金流（场外净值场景资金流缺失按中性处理）+ 历史分位
- 买入辅助：动量转正 + MACD 金叉才考虑进场（右侧）
- 卖出优先、不恋战：20 日动量转负 → 关注；MACD 死叉 / 跌破趋势 → 建议减仓 / 离场
- 主动混合基金申赎成本高，调仓频率低于行业联接基金

## 持仓分类与评分体系

持仓按投资行为分三类，每类一套评分权重 + 决策输出（`Code/lib/metrics.py`）：

| 分类 | 行为 | 核心信号（权重） | 决策输出 |
|---|---|---|---|
| 指数 | 逆向·定投 | PE/价格分位 35 + 趋势 20 + 60日动量 15 + 回撤 15 | 定投倍数 ×1.5 / ×1.0 / ×0.5 |
| 红利 | 逆向·波段 | 价格分位 35 + 股息率利差 20 + 动量方向 15 | 买入区 / 持有 / 卖出区 |
| 行业 | 顺势·波段 | 20日动量 30 + MACD 20 + 资金流 15 + 5日动量 10 | 持有 / 关注 / 减仓 / 离场 |

数据全部用**场外基金净值**（天天基金接口，按基金代码直接拉，T+1 与申赎节奏一致），不映射场内 ETF；指数 PE 估值分位暂未接入（乐咕接口待选型），当前用价格分位兜底。

## 2. 持仓基金分析报告

- [持仓基金分析报告](PortfolioReport/20260818.html)：分析 portfolio.db 中**全部持仓基金**（指数 + 红利 + 行业 + 资金池）。
- 报告按三类分组输出决策：**指数=定投倍数、红利=买入区/卖出区、行业=持有/关注/减仓/离场**，每只基金附综合分、动量、分位、MACD、回撤与预警。
- 数据流：portfolio.db（持仓）→ fund_data 按基金代码拉场外净值（天天基金）→ 三类评分 → 决策输出。
- 录流水时选类别（指数/红利/行业/资金池）即可，基金名与代码手动输入，无需任何映射配置。

使用（统一入口）：

```powershell
.\.venv\Scripts\python.exe .\run.py --index    # 同步持仓 + 增量拉净值 + 生成报告
.\.venv\Scripts\python.exe .\Code\portfolio_report.py --no-refresh   # 跳过拉取，只读缓存生成
```

打开 `PortfolioReport\YYYYMMDD.html`（按数据日期命名，每天一份，历史报告保留不覆盖）查看。

## 3. 板块分析报告

- **板块全景**由 `run.py --plate` 承担：用同花顺官方板块体系（行业 90 + 概念 375，类似同花顺 App 的分类）取代自建关键词分组，板块指数 K 线算 5/20/60 日动量、250 日分位、MACD、资金流、综合分，输出板块全景 / 低估方向 / 强势方向 / 当日涨跌排行。
- 数据源为**同花顺（akshare）**，脚本独立运行、无需注册/token、不限流：板块清单、行业实时快照（一次全量）、板块指数 K 线。数据缓存在 `Code/data/plate.db`，`run.py --plate` 自动增量同步（已最新则跳过）。
- 旧的行业全市场维护（fetch_db + market_industry.db）、行业识别（signal_lib）、场外映射（otc_map）、指数定投库（dca/db + market_index.db）已于 2026-08-17 废弃，备份在根目录 `backup_old/`。

```powershell
.\.venv\Scripts\python.exe .\run.py --plate   # 生成板块分析（--no-refresh 跳过网络）→ PlateReport/YYYYMMDD.html
```

- 打开 `PlateReport\YYYYMMDD.html`（按数据日期命名）查看。
- **历史报告保留**：报告统一命名 `YYYYMMDD.html`，同一天多次生成覆盖当天文件，历史日期的报告不删除。

## 5. 流水记录

所有买入/卖出/资金池流水在持仓管理界面录入（`python run.py --portfolio`，浏览器 http://127.0.0.1:8051）：

- **基金名/代码**：手动输入，输入框带历史基金名补全提示（不限制输入）
- **分类**：指数 / 红利 / 行业 / 资金池（决定报告里的评分策略）
- **删除**：点击「删」变红底「确认?」，3 秒内再点一次即删除（两步确认）
- 流水变更后自动同步：README 持仓表（第 4 节）与 fund_data 持仓快照
