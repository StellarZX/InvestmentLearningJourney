# 投资方法与记录


## 目录结构
这个仓库记录我的投资方法、执行记录与复盘。

> **统一入口**：根目录 `run.py` 通过参数调用全部功能：
> - `python run.py --index` → 持仓基金分析报告（生成 `PortfolioReport/YYYYMMDD.html`）
> - `python run.py --plate` → 板块分析报告（生成 `PlateReport/YYYYMMDD.html`，东财官方行业+概念）
> - `python run.py --portfolio` → 流水记录（http://127.0.0.1:8051）
>
> **目录结构**：
> - `run.py`：统一入口（--index / --plate / --portfolio / --export；--sector 为 --plate 的兼容别名）
> - `Code/plate_data.py` + `Code/plate_report.py`：板块分析（东财官方行业板块 + 概念板块，板块指数 K 线算动量/分位/MACD → `PlateReport/`）
> - `Code/portfolio_report.py`：持仓基金分析报告（全部持仓基金 → 指数/主题信号 → `PortfolioReport/`；行业信号引擎已自合并，不再依赖旧 sector_report）
> - `Code/fetch_db.py`：行业行情维护（腾讯前复权，增量/全量/按类型扩展）
> - `Code/portfolio_app.py` / `.exe`：流水记录（增删改查，浏览器 8051）
> - `Code/export_positions.py`：持仓汇总表生成（第 4 节）
> - `Code/data/`：portfolio.db（持仓流水）/ market_index.db（指数行情）/ market_industry.db（行业行情）/ plate.db（板块清单+K线）
> - `Code/lib/metrics.py`：公共指标引擎（动量/MACD/分位/综合分）；`lib/signal_lib.py`：行业识别/MACD；`lib/otc_map.py`：场外基金→主题映射
> - `PortfolioReport/`、`PlateReport/`：报告输出目录（历史宽基指数报告与旧行业日报已停用，旧文件归档于 `.workbuddy/archive/`）

## 投资体系

整个投资体系分为两个部分：**长期资产（核心）**、行业基金（增强）。

| 部分 | A股长期指数 | 美股长期指数 |   行业基金   |
|:--:|:------:|:------:|:--------:|
| 方式 |  每月定投  |  每月定投  |  不固定投入   |
| 占比 |  60%   |  40%   | < ¥5,000 |

长期指数投资是核心，行业基金只是增强收益。

### A股长期指数

| 指数 | 沪深300 | 中证500 | 创业板 | 恒生指数 | **合计** |
|---:|---:|---:|---:|---:|---:|
| 比例 | 35% | 25% | 15% | 25% | **100%** |


- 沪深300：中国核心资产（银行、保险、消费、制造业龙头），负责稳定。
- 中证500：中盘成长，提高长期收益。
- 创业板：科技创新，成长性最高，比例不宜太高。
- 恒生指数：配置香港上市的中国优质企业（腾讯、阿里、小米、网易等），很多优秀公司不在 A 股上市。
- 注：持仓分析覆盖全部指数持仓（含中证红利、恒生红利低波、美股标普500/纳斯达克100），数据按当前持仓涉及指数拉取（持仓驱动）。

估值调整机制: 战略比例**永远不变**，便宜多买、贵时少买，避免择时：

- 历史分位: <30%：买入 1.5 倍
- 历史分位: 30% ~ 70%：正常投入
- 历史分位: >70%：买入 0.5 倍


### 美股指数

持仓中的标普500/纳斯达克100 纳入持仓基金分析报告（持仓驱动拉取 Yahoo 行情），不再单独做定投分配。

## 2. 持仓基金分析报告

- [持仓基金分析报告](PortfolioReport/20260817.html)：分析 portfolio.db 中**全部持仓基金**（指数 + 行业 + 资金池）。
- 报告内容：指数持仓分析（全部指数持仓含红利/美股：分位/回撤/趋势/健康度 + 预警）、行业持仓分析（映射主题：综合分/分位/动量/MACD + 预警）、资金池余额。
- 指数数据 `Code/data/market_index.db`（持仓驱动：仅拉当前持仓涉及的指数，新浪/腾讯/Yahoo，过旧自动刷新）；行业数据 `Code/data/market_industry.db`（腾讯前复权，自动增量更新）；持仓 `Code/data/portfolio.db`。

使用（统一入口）：

```powershell
.\.venv\Scripts\python.exe .\run.py --index                     # 生成持仓基金分析报告（数据过旧自动刷新）
.\.venv\Scripts\python.exe .\Code\portfolio_report.py --refresh # 强制刷新指数数据后生成
```

打开 `PortfolioReport\YYYYMMDD.html`（按数据日期命名，每天一份，历史报告保留不覆盖）查看。

## 3. 行业报告（已并入持仓分析 + 板块分析）

- **持仓分析**由第 2 节 `run.py --index`（PortfolioReport）统一承担：全部持仓基金（指数/行业/资金池）逐只分析，行业持仓用 `Code/lib/otc_map.py` 映射主题 + 场内代表 ETF 信号代理（综合分/分位/动量/MACD/预警）
- **板块全景**由 `run.py --plate`（PlateReport）承担：用东财官方板块体系（行业板块 + 概念板块，类似同花顺）取代自建关键词分组，板块指数 K 线算 5/20/60 日动量、250 日分位、MACD、资金流、综合分，输出板块全景 / 低估 / 强势 / 当日涨跌排行
- 行业行情库：`Code/data/market_industry.db`（全市场清单 + 行业型 K 线，腾讯前复权；名称用腾讯全称统一，清单代码来自新浪，双源互补）；板块数据在 `Code/data/plate.db`
- 旧 `Code/sector_report.py`（自建分组行业日报）已于 2026-08-17 废弃删除，其行业信号引擎合并进 `Code/portfolio_report.py`，指标引擎抽到 `Code/lib/metrics.py`

### 生成板块分析报告

```powershell
.\.venv\Scripts\python.exe .\run.py --plate   # 生成板块分析（--no-refresh 跳过网络）→ PlateReport/YYYYMMDD.html
```

- 打开 `PlateReport\YYYYMMDD.html`（按数据日期命名）查看：行业/概念板块全景、低估方向、强势方向、当日涨跌排行
- **历史报告保留**：报告统一命名 `YYYYMMDD.html`，同一天多次生成覆盖当天文件，历史日期的报告不删除
- **记录买卖**：`python run.py --portfolio`（或双击 `Code\portfolio_app.exe`），浏览器打开 http://127.0.0.1:8051 录入——指数基金下拉自动带代码，行业自由输入，余额宝资金池记转入/转出
- **更新行情**：`run.py --plate` 运行时会自动增量更新（数据已最新则跳过）；行业手动：`python Code\fetch_db.py`（腾讯前复权，日常秒级）
