# 05 量化投资学习路线

> 量化不是"稳赚"的捷径。它是一套用数据、规则和系统来做出投资决策的方法：让每一次买卖都有依据、可回测、可复盘。
> 本目录从零开始，帮助你在这个仓库已有行情数据系统的基础上，逐步建立量化能力。

## 快速上手示例

- 示例 notebook：[01_量化买入分析示例.ipynb](01_量化买入分析示例.ipynb)（用沪深 300 真实数据演示"估值定投"完整流程：读数据 → 看估值 → 看风险 → 定规则 → 回测 → 看当前信号）
- English: [README.en.md](README.en.md)
- 运行方式：在仓库根目录执行 `.\.venv\Scripts\python.exe -m jupyter notebook`，然后打开 `05_量化` 文件夹里的 notebook。

## 0. 先想清楚：你要的"量化赚钱"是哪一种

| 类型 | 特点 | 适合个人吗 |
|---|---|---|
| 量化投资（低频） | 周/月级别调仓，指数增强、估值定投、资产配置 | 适合，和长期投资兼容 |
| 量化交易（中频） | 日级别策略，网格、动量轮动、趋势跟随 | 可以做，但需要更多时间 |
| 高频交易 | 秒/毫秒级别，拼速度和基础设施 | 不适合个人，成本极高 |

**现实预期：** 量化不能保证赚钱。它的真正价值是纪律（不凭感觉操作）、可验证（历史回测）、可复盘（错了知道错在哪）。

## 1. 第一阶段：打好工具基础（约 2-4 周）

- Python 基础：变量、列表、字典、函数、循环、条件。
- pandas / numpy：DataFrame 的读取、筛选、计算、合并。
- 可视化：matplotlib 或 plotly，画出价格和指标曲线。
- 练习素材：直接用本仓库 `02_Market/data/indices/` 下的 CSV 数据，例如读取标普 500 并计算日收益率。

建议每天 30-60 分钟，边学边在本目录记录笔记。

## 2. 第二阶段：理解量化策略的原料（约 2-3 周）

- 数据：OHLCV（开盘/最高/最低/收盘/成交量）、指数、估值（PE、PB、股息率）。
- 指标：收益率、年化波动率、最大回撤、夏普比率、胜率。
- 经典思路：
  - 动量（momentum）：强者恒强，买过去表现最好的资产。
  - 反转/均值回归（mean reversion）：涨多了会回调，跌多了会修复。
  - 网格交易：在设定区间内分批低买高卖。
  - 估值定投：便宜（低 PE/PB 分位）多买，贵了少买或停投。
- 同步积累金融英语词汇（参考 `04_Glossary/Vocabulary.md`）。

## 3. 第三阶段：写第一个策略并回测（约 4-6 周）

推荐从以下三个简单策略中选一个起步：

1. **定投 vs 一次性投入对比**：用历史数据比较"每月固定金额买入"和"期初一次性买入"的最终收益与回撤。
2. **双均线策略**：价格上穿 50/200 日均线时持有，下穿时空仓，统计长期表现。
3. **月度动量轮动**：每月初比较各指数过去 6 个月收益，持有最强的一个，下月重排。

回测工具选择：

- 自写简单回测：逻辑透明，适合学习。
- vectorbt：快，适合批量比较参数。
- backtrader：功能全，文档多。

**必须计入的成本：** 手续费、滑点、基金申赎费、税费；忽略这些，回测收益会严重虚高。

## 4. 第四阶段：识别"回测骗局"（约 2 周）

- 过拟合：参数调得越多越漂亮，越可能是拟合噪声。参数越少、逻辑越简单，越稳健。
- 样本外验证：把最近 20-30% 的数据留出来，绝不用于调参，最后只测一次。
- 前视偏差：只用当时真实可得的数据（如用下个月的数据"预测"本月是作弊）。
- 幸存者偏差：只回测现在还活着的指数/股票会高估收益。
- 常识检验：如果回测年化 50% 还没有回撤，几乎可以断定哪里出错了。

## 5. 第五阶段：验证与实盘（持续）

- 先在模拟盘跑 2-3 个月，验证实盘执行与回测一致。
- 小资金实盘起步（例如 ¥1,000），亏光也不影响生活的那种。
- 每次交易写日志：为什么买、预期是什么、事后发生了什么、下次怎么改。
- 和你的长期投资结合：把量化信号当作"加仓/减仓的参考"，而不是频繁交易的借口。

## 风险提示

- 量化策略过往表现不代表未来收益。
- 不要投入生活必需资金，不要借钱、不要加杠杆。
- 如果你的策略 3-6 个月跑输简单定投，很可能说明它并不比无脑定投更好——这也是有用的结论。
